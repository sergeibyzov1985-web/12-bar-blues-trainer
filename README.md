# Двенадцать тактов

Тренажёр 12-тактного блюза на пианино для тех, кто играет пару месяцев и почти не знает сольфеджио. Одна тональность — до. В каждой руке только большой палец и мизинец.

Круг всегда один:

```
до  до  до  до
фа  фа  до  до
соль фа  до  соль
```

Левая рука чередует нижнюю ноту такта и её пару: до–соль, фа–до, соль–ре. Правая все двенадцать тактов играет один рифф: до, соль, си-бемоль, соль.

## Как заниматься

1. Слушать круг и считать вслух: раз, два, три, четыре.
2. Собрать левую. Если рука путается на переезде — зациклить этот такт.
3. Выучить правый рифф отдельно. Чёрная клавиша одна: си-бемоль, сразу слева от си.
4. Соединить руки на медленном темпе. Ноты короткие, их не держат.
5. Выключить звуковую подсказку и сыграть круг самому.

На шаге «Сам» тренажёр отмечает попадания в долю. Рядом с инструментом можно открыть шпаргалку внизу страницы.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на [http://127.0.0.1:4317](http://127.0.0.1:4317).

Готовый сайт для nginx собирается в папку `out`:

```bash
npm run build
```

Проверка рисунка и круга:

```bash
npm test
```
